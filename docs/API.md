# API Reference

## Overview

Edyfra exposes two API surfaces:

1. **Server Actions** — form-based mutations
2. **REST API Routes** — JSON endpoints for external integrations

## Authentication

All endpoints require authentication unless otherwise specified. Authentication is handled server-side.

## Rate Limiting

All API routes enforce rate limiting to prevent abuse.

## Webhooks

Webhook endpoints validate requests using shared secrets.

See internal documentation for full API specifications.

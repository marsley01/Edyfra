# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.x     | ✅ Active development |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email us directly at:
- **mashmarsley@gmail.com**
- **edyfraplatform@gmail.com**

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Proof of concept (if available)

### Our Process

1. **Acknowledgement** — within 48 hours
2. **Evaluation** — priority and severity assessment
3. **Fix** — development of a patch
4. **Release** — coordinated public disclosure

Thank you for helping keep Edyfra safe.
